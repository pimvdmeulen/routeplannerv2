# OG-routeplanner (Streamlit-prototype)

⚠️ **Dit is het oorspronkelijke Python/Streamlit-prototype — niet meer de
actieve versie.** De functionaliteit hiervan (routes met OG-tankstopps,
kostenvergelijking, kaart, CSV-export) is overgezet naar vanilla JS en
samengevoegd met de TCO-calculator in één app:

`Desktop/tco-calculator/index.html` (+ `fuel-assumptions.js`,
`og-stations.js`, `cng-stations.js`, `route-engine.js`)

Zie `Desktop/tco-calculator/SETUP.md` voor installatie/deploy-instructies.

Deze map (`app.py`, `og_stations.py`, `cng_stations.py`) blijft alleen staan
als referentie/bron van de oorspronkelijke stationsdata en rekenlogica —
niet meer bijwerken.
